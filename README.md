# SurplusLink

SurplusLink is a platform that helps connect food providers with nearby NGOs to reduce surplus food waste.

## Features

- Nearby surplus food
- Create food listings
- NGO verification
- Request and reserve food
- Pickup confirmation
- Provider analytics
- Leaderboard

## Tech Stack

- HTML
- CSS
- Figma
